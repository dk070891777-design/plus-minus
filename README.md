# +− Плюс-мінус

Облік витрат і доходів. Працює в браузері й ставиться на телефон чи планшет як звичайний застосунок.

**Відкрити:** https://dk070891777-design.github.io/plus-minus/

## Як поставити
- **iPhone / iPad:** відкрийте посилання в Safari → «Поділитися» → «На екран Додому» → «Додати».
- **Android:** відкрийте посилання в Chrome → меню ⋮ → «Встановити застосунок» або «Додати на головний екран».

Записи зберігаються на самому пристрої. Щоб перенести їх на інший пристрій, у «Налаштуваннях» натисніть «Резервна копія», а там — «Відновити з резервної копії».
